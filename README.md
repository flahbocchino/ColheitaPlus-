# 🌱 ColheitaPlus

Sistema para análise de perdas na colheita de cana-de-açúcar, com foco na eficiência por operador e máquina.

## 🚀 Objetivo

Este projeto tem como objetivo permitir o registro e a análise de colheitas de cana, estimando perdas e organizando dados por operador, tipo de colheita e máquina usada.

---

## 🧠 Funcionalidades
- Cadastrar operadores
- Cadastrar máquinas
- Registrar colheitas (manuais ou mecanizadas)
- Estimar perdas em %
- Armazenamento em arquivos `.json`
- Organização em Python modular

---

## 🛠️ Tecnologias usadas

- Python 3
- Google Colab
- GitHub
- JSON (para persistência de dados)
